A. 단기 직원 폼 사용법 (현장 안내문 그대로)

  1. 현장 전용 기기(2대)에 열려 있는 「한결맛담 추석 단기 출퇴근 체크」 화면을 쓴다. 본인 폰으로 링크를 받지 않는다.
  2. 출근하면 바로: 구분 = 출근 → 이름 = 본인 이름 고르기 → 제출.
  3. 퇴근할 때 똑같이: 구분 = 퇴근 → 이름 → 제출.
  4. 잘못 눌렀으면 다시 제출하면 된다(나중 것을 봄). 대표에게 한마디.
  5. 이름이 목록에 없으면(첫날) 대표에게 말한다 → 대표가 수기로 적고, 이름 추가.
  6. 파트 시간 밖 기록은 자동으로 파트 시간에 맞춰 인정된다(예: 13:55 출근 → 14:30부터). 일찍 오거나 늦게 남는 건 대표가 부탁한 날만 인정.

B. 대표 수기 입력법 (폼을 못 쓴 날)

  2. 맨 아래 빈 줄로: Ctrl+↓ 그다음 ↓.
  3. 왼쪽부터 Tab으로 이동하며 적기: 날짜(2026-09-04) → 이름 → 파트 → 출근(14:30) → 퇴근 → 근무시간(비워도 됨) → 시급(10,320) → 일급(비워도 됨) → 기록(수기) → 비고("대표 확인 기재" + 이유).
